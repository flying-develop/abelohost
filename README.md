# Блог на PHP, MySQL и Smarty

Тестовое задание: блог на чистом PHP без фреймворков. Стек проекта: PHP 8.4, MySQL 8.4, Smarty 5, Bootstrap, SCSS и Vite. Окружение запускается через Docker Compose.

Главная показывает категории с тремя последними статьями и ссылкой «Все статьи». Карточки содержат превью, заголовок и дату. Оформление вдохновлено Twenty Twenty. Страницы статей и категорий пока не реализованы; ссылки `/articles/{id}` и `/categories/{id}` возвращают 404.

## Требования задания

- Категория: название и описание.
- Статья: изображение, название, описание, текст, одна или несколько категорий, количество просмотров и дата публикации.
- Главная: категории с тремя последними статьями и кнопкой «Все статьи» для каждой категории.
- Страница категории: описание, статьи, сортировка по просмотрам и дате, пагинация.
- Страница статьи: полная информация и три похожие статьи.
- Сидинг категорий и статей.

Оцениваются читаемость кода, структура проекта, работа с MySQL и понимание решения. SCSS и Docker — плюс. Результат сдаётся ссылкой на открытый репозиторий с указанием использования ИИ; желательны поэтапные коммиты.

## Запуск

Нужны Docker и Docker Compose.

```bash
cp .env.example .env
mkdir -p ../abelo-storage/mysql
docker compose build php-fpm
docker compose run --rm --no-deps php-fpm composer install
docker compose run --rm --no-deps node npm ci
docker compose run --rm --no-deps node npm run build
docker compose up -d
```

Перед запуском задайте пароли в `.env`. На Linux укажите `LOCAL_UID` и `LOCAL_GID` по результатам `id -u` и `id -g`.

Сайт: http://localhost:8080.

## Структура

- `public/index.php` — точка входа; `app/` — MVC: модели, контроллеры, сервисы и репозитории PDO; `templates/` — представления Smarty. Carbon используется для дат в UTC.
- `src/js`, `src/scss`, `src/images` — ресурсы дизайна, собираемые в `public/build` с очисткой каталога.
- `src/data/articles` — изображения статей, копируемые при запуске PHP в `public/data/articles`. Публичные копии исключены из Git.
- `docker/` — конфигурация окружения и SQL-скрипты.

MySQL хранит данные в `../abelo-storage/mysql`. При первом запуске с пустым хранилищем автоматически создаются таблицы `categories`, `articles`, `article_categories` и добавляются три категории с тремя статьями в каждой. Для существующего хранилища SQL-скрипты автоматически не повторяются.

## Разработка

```bash
docker compose run --rm --no-deps node npm run watch # пересборка ресурсов
docker compose restart php-fpm                      # обновление копий изображений
docker compose logs -f                             # журналы контейнеров
docker compose down                                # остановка окружения
```

Проверка главной и репозитория на MySQL: `docker compose exec -T php-fpm php tests/home.php`. Временные данные проверки откатываются транзакцией.
